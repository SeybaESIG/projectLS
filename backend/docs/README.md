# Documentation du Backend

Ce répertoire contient toute la documentation du projet, organisée en deux catégories :

## Structure

```
docs/
├── github/          # Documentation destinée à GitHub
│                   # Tous les guides et configurations
│
└── local/          # Notes de développement (non commitées)
                    # Résumés de sessions et guides pédagogiques
```

## Contenu

### `docs/github/` - Documentation publique

Documentation visible sur GitHub et utile pour les développeurs :

- **ADMIN_ROLES_GUIDE.md** - Gestion des rôles administrateurs
- **API_PERMISSIONS.md** - Système de permissions de l'API
- **FIREBASE_AUTH_SETUP.md** - Configuration Firebase Authentication
- **GCS_UPLOAD_SETUP.md** - Configuration Google Cloud Storage
- **STRIPE_SETUP.md** - Configuration Stripe
- **DATABASE_INDEXES.md** - Liste des indexes de la base de données
- **SQL_OPTIMIZATION_GUIDE.md** - Guide d'optimisation SQL
- **Et d'autres guides techniques...**

### `docs/local/` - Notes de développement

Documentation interne non commitée sur GitHub :

- **GUIDE_PEDAGOGIQUE_COMPLET.md** - Guide pédagogique détaillé
- **FINAL_SUMMARY.md** - Résumé final de session
- **IMPLEMENTATION_SUMMARY.md** - Résumé d'implémentation
- **SECURITY_IMPLEMENTATION_SUMMARY.md** - Résumé sécurité
- **FIREBASE_IMPLEMENTATION_SUMMARY.md** - Résumé Firebase

---

**Note** : `README.md` à la racine `backend/` reste le point d'entrée principal du projet.
